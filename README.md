# Проверенные подрядчики — Система ОП

Картотека проверенных специалистов (интеграторы, подрядчики), которые работали с командой «Система ОП».
Одна страница `index.html`, деплой на GitHub Pages. Домен: partners.systemop.top

## Как добавить специалиста
1. Положи фото в папку `img/` (например `spec-02.jpg`).
2. В `index.html` найди список `SPECIALISTS` и скопируй один блок `{ ... }`, заполни поля.
   Номер WhatsApp — только цифрами, без + и пробелов.
